# Website thử nghiệm PXL

Giải nén ZIP và mở index.html để xem giao diện. Để thử đầy đủ, mở máy chủ tĩnh từ thư mục cha bằng `python -m http.server 8000` và vào http://localhost:8000/TEN-THU-MUC/.

## Đưa lên GitHub Pages

1. Tạo repository thử nghiệm, ví dụ pxl-website-test. Chỉ tải lên nội dung được phép công khai.
2. Trong tab Code, chọn Add file → Upload files. Tải nội dung đã giải nén sao cho index.html, assets/ và image/ cùng cấp. Commit vào main.
3. Vào Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Khi triển khai xong, mở Visit site. Kiểm tra đủ 5 trang và thử mã DEMO-PXL-001.
5. Thử báo giá hàng thông thường và hàng dự án. Sau khi xem lại, bấm sao chép hoặc mở bản nháp email. Người dùng tự gửi trong ứng dụng email.

Bản thử không cần thư viện hoặc backend. Không có giá tự động hay kết nối điều độ. Các ảnh được ghi công cạnh ảnh, hồ sơ nguồn nằm trong image/IMAGE_SOURCES.csv.
